# SmartTech Kerala website

Complete static website. No installation or build required.

## GitHub Pages
1. Extract this ZIP.
2. Upload all extracted files and the assets folder to the repository root. Keep index.html at the root, not inside another folder.
3. In Settings > Pages, select Deploy from a branch, then main and / (root).
4. CNAME contains india.smarttechsecuritysolution.com. Configure the corresponding DNS record at your domain provider. GitHub Pages shows the required configuration. Enable HTTPS after DNS verification completes.

Preview locally by opening index.html in a browser.

## Asset folders
- assets/logo: SmartTech logo.
- assets/services: hero and service photos.
- assets/clients: client logos.

## Clients
Edit the original four article elements inside .client-track in index.html to add or update clients. Copy an article, change its image, name and location, and add the logo file to assets/clients. JavaScript duplicates the row for continuous movement; do not add duplicate clients manually.

Photos are illustrative generated images, not actual project photographs. Supplied brand and client logos are preserved.
